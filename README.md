# convex-hull

平面凸包（Andrew 单调链），只用 Go 标准库。

```
go test ./...
go run ./cmd/convex-hull --sample square-mid
go run ./cmd/convex-hull --points '0,0;4,0;4,4;0,4;2,2'
```

## 口径（README 为准）

- **共线的中间点要去掉**：叉积判定要用 `<= 0`（只要不是严格左转就出栈）。
  `--sample square-mid`（正方形四条边的中点）按口径凸包是 4 个角点，现在因为用 `< 0`，
  四个中点全留在结果里，给 `hull=8`。
- 输出：逆时针顺序，起点是最左下角那一点；重复点要去重；点数 < 3 或去重后不足 3 个点要报错。
- 不变量：结果里每个点都来自输入；结果是凸多边形（相邻三点不右转）；与「枚举所有点对判定是否在边界上」
  的暴力实现给出的顶点集合一致。
- 规模：100 万个随机点要在 1 秒内算完，内存 O(n)；不许用 O(n³) 的暴力判边法。

## 现在的行为

- `build` 的条件是 `cross(...) < 0`：共线的点不会被弹出，凸包里会留下边上的中间点。
- 内部点处理是对的（严格叉积为负时会弹出），`--points '...;2,2'` 这种内部点没问题。

## 计划新增的能力

```
--points 点集    分号分隔的 x,y
--sample 名称    square / square-mid
```

## 输出

```
points=8 hull=4 (0,0) (4,0) (4,4) (0,4)
```
